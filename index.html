If this message is still here after a few seconds, the app’s files did not load. Check these in order:

  1. Folder layout. index.html must sit next to the folders css/, fonts/, js/ and js/mobile/. Files must not be mixed into one folder: 
    cali30/
  index.html
  css/     tailwind.css  fonts.css  styles.css
  fonts/   (the .woff2 files)
  js/      log.js security.js data.js store.js state.js icons.js utils.js components.js pages.js
           analytics.js skills.js diagnostics.js session.js main.js
  js/mobile/  m-shell.js m-home.js m-workouts.js m-library.js m-progress.js m-schedule.js m-session.js m-profile.js
  2. Open it from a server. In VS Code: right-click index.html → Open with Live Server.
  3. Find the missing file. Press F12 → Console (or Network): red lines name every file that was not found.
  4. Easiest fix: unzip cali30.zip (it keeps the folders exactly right). More help: README.md and docs/TROUBLESHOOTING.md.
